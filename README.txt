============================================================
 WaveScout v1.0.0  -  Free Portable Windows WiFi Analyser
 by VaultSoft
============================================================

WHAT IT DOES
  Scans nearby WiFi networks and shows signal strength, channel
  congestion, security and a live signal graph in a clean dark UI.

HOW TO RUN
  Just double-click WaveScout.exe. No installation, no admin
  rights needed for basic scanning. It minimises to the system
  tray when you close the window (right-click the tray icon to
  exit).

FEATURES
  - Live network table: SSID, signal (dBm + % bar), channel,
    band (2.4 / 5 / 6 GHz), security, BSSID. Rescans every 5s.
  - Channel congestion charts with a "best channel" recommendation.
  - Rolling 60-second live signal graph.
  - Your connection panel: IP, gateway, DNS, channel, band, etc.
  - System-tray signal indicator.

IMPORTANT - LOCATION SERVICES
  Windows 10/11 require Location services to be ON for ANY app to
  read WiFi scan results. If it is off, WaveScout shows a banner
  telling you so. Turn it on under:
      Settings > Privacy & security > Location
  ...and the network list fills in automatically. Your current
  connection details work either way.

NOTE ON dBm
  Windows reports signal as a 0-100% quality value. The dBm figure
  shown is estimated (0% ~ -100 dBm, 100% ~ -50 dBm).

SYSTEM REQUIREMENTS
  Windows 10/11 64-bit, a WiFi adapter.
